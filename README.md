# Bandz HTF Statistical Zones | Sessions & Price Targets

Free, open-source Pine Script v6 indicator. The chart short title is **HTF Zones**.

[Complete source](HTF_Statistical_Zones.pine) | [Raw code](https://raw.githubusercontent.com/samuelharting/bandz-htf-statistical-zones/main/HTF_Statistical_Zones.pine)

## Features

- Daily percentile zones anchored to the 18:00 New York open.
- AM, midday, and PM session zones and 15/30-minute opening ranges.
- Historical target estimates, prior-day and overnight levels, and invalidation levels.
- Asia stat boxes (where the Asia high / low usually lands), optional four-hour levels, a statistics table, and minimal mode.
- Statistics sets for NQ/MNQ, ES/MES, YM/MYM, and GC/MGC.

## Use in TradingView

1. Open the source above, select **Raw**, and copy all the code.
2. Open TradingView's Pine Editor and create a new indicator.
3. Replace the starter code, save, and select **Add to chart**.
4. Choose the inputs for your market and chart.

No Whop subscription or invite-only approval is required to use this source.
